# 딱필모 사용성·품질 점검 — 2026-09-13

## 범위와 기준

학생·학부모·교사가 사이트를 직접 검색하거나 자료 탐색 가이드를 따라 추천 사이트의 상세정보를 확인하고 외부로 이동하는 흐름을 점검했다. 기존 서비스 허브, 밝은 배경·청록색 강조, 상세정보 분리, 저장 키와 중복 통합을 유지했다. 운영 배포·시트 수정·데이터 삭제·신규 외부 서비스 연결은 하지 않았다.

프로젝트 및 상위 경로에서 별도 AGENTS.md를 찾지 못했으며 README와 리디자인 운영 문서를 확인했다. 정적 HTML/CSS/ES 모듈 프로젝트이고 `npm run serve`로 4173 포트에서 실행한다. 활성 진입점은 `js/hub/app.module.js`, 카탈로그는 `js/data/sheet-catalog.module.js`다. 별도 빌드 명령은 없다. 작업 시작 전부터 있던 미커밋 리디자인 변경을 유지했다.

## 확인한 문제와 실제 개선

P1은 탐색을 막거나 정보 상태를 오인하게 하는 문제, P2는 접근성과 탐색 효율, P3는 보완 항목이다. 사용자 영향은 관찰된 동작에 따른 판단이며 사용자 조사 결과를 의미하지 않는다.

|---|---|---|---|

| P1 | 브라우저 재현: `#/guide?purpose=concept&step=2`에서 학교급 없이 과목 단계 진입 | 결과를 열지 못하고 돌아가야 함 | 누락된 필수 학교급 단계로 복귀 |

| P2 | 코드 확인: 검색할 때 표시하지 않을 전체 목록까지 다시 생성 | 입력마다 불필요한 카드 문자열 생성·파싱 | 적용 필터 렌더링을 별도 함수로 추출. 실제 속도 개선 수치는 측정하지 않음 |
| P2 | 코드 확인: 선택 콘텐츠 요청에 시간 제한이 없고 카탈로그보다 먼저 순차 대기 | 선택 콘텐츠 지연이 사이트 진입을 지연시킬 수 있음 | 선택 콘텐츠에 3초 제한, 카탈로그와 병렬 요청. 대기 안내 개선 |

추가로 더 이상 사용하지 않는 select 기반 설정 제출 분기를 제거했다. 새 데이터 연결이나 사용자에게 보이는 가짜 기능은 추가하지 않았다.

## 검증 결과

- 변경 전: ESLint 통과, 단위 테스트 34개·Playwright 13개 통과.
- 변경 후: ESLint 통과, 단위 테스트 37개·Playwright 19개 통과. 마지막 모바일 가이드 배치 변경 후 관련 반응형·가이드 테스트 6개를 다시 실행하여 통과.
- 실제 Google Sheets API 연결: source=google-sheets, 고유 사이트 156개, 카테고리 13개, 제외 경고 0개. 원본 160행의 기존 중복 통합 유지.
- Chromium 실제 실행: 홈·목록·상세·선택형 가이드·보관함·기존 주제별 가이드, 검색·필터·복사·저장·뒤로가기 확인. 최종 실시간 대표 페이지 탐색에서 pageerror 0건.
- 390·768·1440·1920px 반응형 테스트, 320px 및 본문 200% 확대 추가 점검. 가로 넘침 없고 설정 창 하단 초기화 버튼까지 스크롤 및 키보드 접근 가능.
- API 실패·백업 실패·잘못된 행·잘못된 주소·저장 거부·복사 거부는 테스트 환경에서 주입하여 검증했다. 운영 장애가 발생했다는 뜻은 아니다.
- 대표 화면을 캡처하여 직접 확인했다. 캡처는 무시 디렉터리 `test-results/screens/`에 저장된다.
- 별도 빌드 스크립트가 없어 빌드는 실행하지 않았다. Lighthouse, 실제 스크린리더, Safari/Firefox, 실기기 검증 및 운영 배포는 수행하지 않았다.

## 남은 과제와 추정 구분

- **확인된 콘텐츠 공백 / P2:** EBS 등 상세 요약의 이용료·가입 조건·운영기관에 미확인 항목이 있다. 공식 근거를 확인한 뒤 구조화 데이터를 채워야 한다. 이번에는 임의의 사실을 추가하지 않았다.
- **구조 확인·영향 미측정 / P2:** 해시 주소와 클라이언트 렌더링을 유지하므로 개별 상세정보의 검색 노출·SNS 미리보기에는 제약이 예상된다. 실제 색인 상태는 조사하지 않았다. 페이지별 정적 HTML 생성은 기존 주소 호환·배포 경로를 포함한 별도 변경으로 남긴다. 기본 메타데이터 추가만으로 해결했다고 보지 않는다.
- **코드 확인·지연 영향 미측정 / P2:** 원격 팁이 비어 있으면 기존 가이드 대체 파일 요청을 최대 10초 기다릴 수 있다. 핵심 카탈로그와 레거시 가이드의 완전한 점진적 로딩 분리는 추가 회귀 검증이 필요한 후속 작업이다.
- **성능 미측정 / P3:** 실제 사용자 Core Web Vitals나 서버 응답 분포를 측정하지 않았다. 로컬 처리 중복은 제거했지만 속도 점수 개선을 주장하지 않는다.
- **코드 확인 / P3:** 과거 렌더러와 새 화면 코드가 공존한다. 호환성 및 기존 가이드 의존성 때문에 이번에는 대규모 삭제·재작성을 하지 않았다.
