# 서비스 전략 구현·검증 현황

기준:2026-10-31. 현재 작업 트리의 기존 수정·미추적 파일을 유지한 상태에서 추가 구현했다. 운영 배포·원격 글 게시·시트 수정·사용자 연락·결제를 실행하지 않았다.

## 구현

- 완성형 검색이 다른 단어와 초성만으로 매칭되던 분기를 제거했다. 자음 전용 검색, 한글 조합, 자동완성은 보존한다. 활성 검색에는 상세 요약·주요 용도·사용 상황도 포함한다.
- 공공 운영 필터는 출처·확인일이 있는 정부·공공기관만 포함한다. 원본 isGov에 의존한 아이콘은 제거하고 검증 문구를 사용한다. 근거 없는 항목은 미확인이다.
- 추천 학교급과 가입 연령을 구분한다. 낮은 결과 수에 학교급 조건만 해제하는 링크를 제공한다. KOSIS는 공식 길라잡이의 공개 통계 활용 흐름에 근거하여 중등 과제 추천을 보완했다. 이는 가입 가능 연령 판정이 아니다.
- 홈의 대형 장식·중복 소개를 줄이고 검색을 첫 화면으로 올렸다. 작업 안내3개, 저장 최대4개·최근 최대3개 이어가기, 정보 글·무료 양식·전체 분류를 제공한다. 기록이 없으면 이어가기 영역을 생략한다.
- 기존 카드 모서리 설정값은 무시한다. 테마·글자 크기·동작 설정과 저장 키는 유지한다.
- 작업 안내3개는 task-statistics/task-literature/task-presentation 고정 ID의 번들 저작물이다. 관리자가 편집하는 Firestore 글과 별개이며 기존 글을 복사·영구 캐시한 것이 아니다. 원격 장애에도 해당 안내는 직접 접속 가능하다. 이3개 ID는 번들 전용으로 예약한다.
- 홈 글 조회에 limit(3)을 적용했다. 전체 목록·검색에는 제한을 적용하지 않는다.
- 무료 탐구·출처 양식을 HTML/Markdown으로 제공한다. HTML은 브라우저 인쇄로 PDF 저장 가능하다. 입력 내용은 서버 전송·자동 저장되지 않으며 새로고침하면 사라진다고 안내한다.
- 공개 시트의 2026-10-30T16:05:04.026Z 응답을 검증한 뒤 백업에 반영했다.167행→162개 사이트,14개 카테고리,상세150건. 백업 생성일을 화면에 표시하며 개별 확인일을 바꾸지 않았다.
- 카탈로그 유지 스크립트와 핵심20개 구조화 검수 대장, 전략서, 관찰·수익 실험 운영 양식을 추가했다.
- Playwright는 설치된 serve를 직접 실행하고 업데이트 확인을 끈다. 이 환경에서 로컬 서버·Chromium 실행은 샌드박스 밖에서 검증했다.

## 검증 결과

- ESLint 통과.
- 단위56개 통과 (검색10사례, 검증 공공 필터, 학교급 해제의 다른 조건 보존, 작업 글 인터페이스 포함).
- Chromium E2E31개 통과. 홈390×844 첫 화면 검색·저장 재방문·오프라인 안내·공공필터·양식 편집을 추가했다.
- 기존 검색 IME·뒤로가기·공유·관리자 권한 UI·비공개·저장 실패·API/백업 장애·320~1920px 회귀를 포함한다.
- 390px 홈 전체 캡처를 시각 확인했다. 테스트 캡처의 사이트 수는 주입한28개 fixture이며 실제 운영 목록 수를 뜻하지 않는다.
- Firestore 규칙은 변경하지 않았다. 이번 실행에서 Emulator 규칙 테스트·실제 스크린리더·실기기·Safari/Firefox·실사용 유지율은 검증하지 않았다.

## 남은 조건부 운영 작업

1. 핵심20개의 시트 수입 정보를 공식 근거와 실제 과제로 독립 재검수한다. 대장의 independentReviewStatus=pending을 완료로 오인하지 않는다. KOSIS 추천 보완과 세 안내의 출처 확인은20개 전체 검수와 다르다.
2. 동의 절차와 모집 후5명 탐색 관찰,15명28일 반복 이용을 진행한다. 미실행이므로 KPI 성과를 보고하지 않는다.
3. 무료 양식10명 중5명 실사용 후 원본 유료 팩을 제작한다. 아직 PDF/편집 문서 유료 최종본·외부 상품 URL·결제는 없다.
4. 거래·권리·환불·판매채널 조건을 충족한 후100회/3건 구매 시험을 한다. 현재 판매 수익은 미측정이다.
5. 별도 이전 사이트의 주소 정리·운영 배포·호스팅 변경은 해당 환경에서 후속 수행한다. 콘텐츠30편 초과 시 커서 페이지네이션·검색 설계를 다시 검토한다.

검증 완료는 구현 범위에 한정한다. 재방문·사업성 검증 완료를 의미하지 않는다.
