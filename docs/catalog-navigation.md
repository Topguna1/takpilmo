# 상세 버튼 및 시트 카테고리 반영

## 상세정보

다른 탭의 localStorage 변경을 전부 감지해 화면 전체를 다시 그리던 동작을 제한했다. 특히 관리자 임시 저장처럼 공개 사이트와 무관한 변경은 무시한다. 테마 변경은 CSS 상태만 바꾸고, 상세페이지의 저장 상태는 버튼 속성·문구만 갱신한다. 클릭 도중 DOM이 교체되는 조건을 방지한다. 관련 카드도 마우스를 올릴 때 위치를 이동시키지 않는다.

상세페이지의 `사이트 주소 복사`는 해당 사이트의 검증된 http/https 외부 URL을 복사한다. 현재 딱필모 주소나 #site 링크를 복사하지 않는다. 클립보드가 거부되면 같은 외부 URL을 선택 가능한 입력란에 표시한다.

## 시트 카테고리

이번 실제 API 확인에서는 167개 행, 중복 통합 후 162개 사이트였고 `textbook` 카테고리 및 교과서 사이트 6개가 이미 존재했다. 누락 원인은 데이터가 아니라 `GROUPS.study.categories`에 textbook이 빠져 있던 것이었다.

- ‘공부·독서’ 하위에 교과서를 포함했다.
- 목적별 분류 줄 오른쪽의 `전체 카테고리 보기`에서 시트의 활성 카테고리를 모두 펼치고 닫는다.
- 여기서 선택하면 목적 그룹 조건을 전체로 바꾸어, 목적 그룹에 아직 배정되지 않은 카테고리도 접근할 수 있다.
- 목록은 시트의 categories 데이터에서 생성하므로 새 카테고리를 전체 카테고리에 표시하기 위해 코드를 수정할 필요가 없다. 카테고리의 key/name과 사이트 행의 category/categories 참조가 맞고 enabled 상태여야 한다.
- ‘공부·독서’ 같은 상위 목적 그룹의 묶음 자체는 별도 정의다. 새 카테고리를 특정 목적 그룹의 하위에도 배치하려면 해당 그룹 정의를 지정해야 하지만, 전체 카테고리 보기에는 그룹 배정 없이 표시된다.
- 시트/API 요청이 실패하면 저장된 백업을 표시하므로 그때의 새 카테고리는 보이지 않을 수 있다. 화면의 백업 안내와 다시 연결을 확인한다. Apps Script 응답 자체에 새 행이 없으면 시트 탭·헤더·enabled 상태와 Apps Script 저장/배포를 별도로 확인해야 한다.

검증: 관리자 임시 저장·테마·북마크의 교차 탭 이벤트 사이의 실제 마우스 클릭, 외부 URL 복사 및 실패 대체 경로, 시트에만 존재하는 신규 카테고리, 교과서 필터, 새로고침, 320px UI를 브라우저 테스트로 확인했다.
