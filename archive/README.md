# 보관 파일

`local-tools/`에는 웹사이트와 무관한 과거 로컬 작업 파일을 보관합니다. 자동 실행하거나 웹사이트에서 불러오지 않습니다.

| 파일 | 원래 위치 | 용도 |
|---|---|---|
| codex-protocol-backup.reg | 저장소 루트 | Codex 프로토콜 레지스트리 백업 |
| codex-protocol-backup-20260531-211309.reg | 저장소 루트 | 날짜별 레지스트리 백업 |
| codex-protocol-backup-before-workaround-20260531-211611.reg | 저장소 루트 | 우회 설정 전 레지스트리 백업 |
| codex-protocol-backup-before-asar-workaround-20260531-212805.reg | 저장소 루트 | ASAR 관련 설정 전 백업 |
| debug.log | 저장소 루트 | 과거 디버그 로그 |
| relay-codex-oauth-callback.ps1 | scripts/ | 과거 Codex 로그인 콜백 전달 보조 스크립트 |

원본을 삭제하지 않고 이동했습니다. 복구가 필요하면 표의 원래 위치로 되돌리면 됩니다. 웹사이트 배포에 필요한 파일은 아닙니다.
